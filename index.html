NeetCode 150 · Spaced Repetition Tracker

Learn in order, review on a schedule that fights forgetting.
How review timing works: each problem you solve enters a review queue using a simplified SM-2 algorithm (the spacing model behind Anki/SuperMemo, validated for durable retention of applied skills, not just facts). First review after 1 day, then 3, then intervals grow by an ease factor (starts at 2.3, adjusted by how each review felt). "Again" resets it to 1 day; "Hard/Good/Easy" grow the gap. Struggling problems resurface sooner; solid ones fade out to long intervals so you spend time where it's actually needed — this is the same spacing-effect logic used to make pattern recognition (not just answer memorization) stick for problem types like sliding window or DP.
Progress is stored only in this browser. Problem list follows NeetCode's published 150 roadmap order; links go to LeetCode.
